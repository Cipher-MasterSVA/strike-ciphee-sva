РУКОВОДСТВО ПОЛЬЗОВАТЕЛЯ (РУССКИЙ)



1. ОБЩЕЕ ОПИСАНИЕ

StrikeCipherSVA — инструмент для шифрования текстов методом книжного шифра
с пометкой использованных символов и удалением символа в ячейке
(Amnesic Book Cipher — амнезия символов).

Программа представляет собой один HTML-файл, открывается в любом современном
браузере, не требует установки и подключения к интернету. Все данные хранятся
локально в IndexedDB браузера.

ОСНОВНОЙ ПРИНЦИП:
Книга — трёхмерный массив символов (Страницы × Строки × Символы).
При шифровании каждый символ сообщения заменяется координатами случайной
свободной ячейки с таким же символом. Использованная ячейка немедленно
УДАЛЯЕТСЯ — символ уничтожается, на его месте остаётся null. Без книги
координаты выглядят как случайный набор чисел.

КЛЮЧЕВОЕ ОТЛИЧИЕ от классического книжного шифра:
Использованные ячейки помечаются, после чего символ уничтожается. Книга
не помнит, какие символы были использованы. После завершения сеанса связи
невозможно доказать, какой символ был в ячейке. Это — «амнезия книги»
(Amnesic Book). Даже при полном доступе к книге постфактум содержание
переписки невосстановимо.


2. УПРАВЛЕНИЕ КНИГАМИ

ТОЧЕЧНОЕ УДАЛЕНИЕ КНИГИ
Выберите книгу из общего списка (обычные и защищённые) и нажмите
«УДАЛИТЬ ВЫБРАННУЮ КНИГУ». Рекомендуется удалять открытую книгу
сразу после создания защищённой копии через раздел «Защита книги».

ПОЛНАЯ ОЧИСТКА БАЗЫ ДАННЫХ
Удаляет все книги (обычные и защищённые) из IndexedDB.
1. Нажмите «УДАЛИТЬ ВСЕ КНИГИ».
2. Подтвердите действие.


3. СОЗДАНИЕ КНИГИ

1. Введите имя книги (латиница/кириллица).
2. Задайте размеры: Страницы, Строки, Символы в строке.
3. Выберите наборы символов: Кириллица, Латиница, Символы, Пробел.
4. Рекомендуется: включите «Крипто-генератор» (crypto.getRandomValues).
5. Нажмите «СОЗДАТЬ КНИГУ».

ИМПОРТ И ЭКСПОРТ:
— Импорт обычной книги — выберите файл .json.
— Экспорт обычной книги — выберите книгу из выпадающего списка
  «Книга для экспорта» и нажмите «Экспорт обычной книги (JSON)».
  Будет сохранён файл с именем выбранной книги.

ВАЖНО: После создания книги она хранится в открытом виде. Сразу после
создания защищённой копии (раздел 4) удалите открытую книгу через
«Управление книгами» → «УДАЛИТЬ ВЫБРАННУЮ КНИГУ».


4. ЗАЩИТА КНИГИ (ВИЖЕНЕР)

Шифрование книги для безопасной передачи по открытым каналам.

ЗАШИФРОВАТЬ КНИГУ (отправитель):
1. Выберите режим «ЗАШИФРОВАТЬ КНИГУ».
2. Выберите обычную книгу и нажмите «Загрузить».
3. Заполните: Алфавит, Ключ, Раунды (рекомендуется 17).
4. Нажмите «ВЫПОЛНИТЬ».
5. Защищённая книга сохранится в IndexedDB с пометкой в имени
   (например, "моя_книга_protected_1738331068899").

ЭКСПОРТ ЗАШИФРОВАННОЙ КНИГИ:
Выберите книгу из выпадающего списка «Зашифрованная книга для экспорта»
и нажмите «Экспорт зашифрованной книги». Будет сохранён файл с именем,
содержащим пометку _protected_ и временную метку.

РАСШИФРОВАТЬ КНИГУ (получатель):
1. Выберите режим «РАСШИФРОВАТЬ КНИГУ».
2. Нажмите «Импорт защищённой книги» и загрузите .json.
3. Выберите книгу и нажмите «Загрузить».
4. Введите те же Алфавит, Ключ и Раунды.
5. Нажмите «ВЫПОЛНИТЬ».

КРИТИЧЕСКИ ВАЖНО: Защищать можно только новую, ни разу не использованную
книгу. Удалённые символы (null) не маскируются шифром Виженера.

АВТООЧИСТКА ПОЛЕЙ ЗАЩИТЫ: Поля алфавита, ключа и раундов имеют таймер
на 1 минуту. Если вы не изменяли их в течение минуты — они сбрасываются
к значениям по умолчанию. Кнопка «Восстановить» также сбрасывает таймер.

ПОСЛЕ СОЗДАНИЯ ЗАЩИЩЁННОЙ КНИГИ: удалите открытую книгу через
«Управление книгами» → «УДАЛИТЬ ВЫБРАННУЮ КНИГУ».


5. ШИФРОВАНИЕ ТЕКСТА (книжный шифр с удалением)

Используется ваша книга (Книга-1).
1. Выберите книгу из списка и нажмите «Загрузить».
2. При загрузке книги введите алфавит, ключ и раунды Виженера.
3. При первой загрузке введите 4-символьный пароль продления таймера.
4. Введите сообщение.
5. Нажмите «ЗАШИФРОВАТЬ».
6. Результат — координаты вида страница:строка:символ.

РЕКОМЕНДАЦИЯ ПО ДЛИНЕ СООБЩЕНИЙ:
Для защиты от анализа трафика старайтесь, чтобы все сообщения были
примерно одинаковой длины. Используйте счётчик символов над полем ввода.
Если сообщение короче нужной длины — дополните его случайными символами
в конце. Если сообщение длиннее — разбейте на несколько частей.
Договоритесь с получателем о стандартной длине заранее (например, 40,
60 или 100 символов). Получатель будет видеть длину вашего сообщения
в счётчике над полем результата и сможет ориентироваться на неё
при ответе.

ЗАЩИТА ОТ КЕЙЛОГЕРА:
Включите галочку «Виртуальная клавиатура» над полем сообщения.
Раскладка клавиатуры случайна при каждом включении и каждой смене режима.
Кейлогер видит только клики по координатам, но не знает раскладку.

СКРЫТИЕ ТЕКСТА:
Вводимый текст скрыт точками. Нажмите и удерживайте кнопку
«👁 Удерживать для просмотра», чтобы увидеть текст.

МГНОВЕННОЕ СОХРАНЕНИЕ:
После каждой операции шифрования или дешифрования книга немедленно
сохраняется в зашифрованном виде в IndexedDB. Отключение электричества
или крах браузера не приведут к потере использованных ячеек.


6. ДЕШИФРОВАНИЕ ТЕКСТА

Используется книга собеседника (Книга-2).
1. Выберите книгу и нажмите «Загрузить».
2. При загрузке введите алфавит, ключ и раунды Виженера.
3. Вставьте координаты в поле «Шифр».
4. Нажмите «РАСШИФРОВАТЬ».
5. Результат скрыт точками. Удерживайте «👁» для просмотра.

СЧЁТЧИК СИМВОЛОВ:
Над полем результата отображается количество символов в расшифрованном
сообщении. Ориентируйтесь на эту длину при составлении ответа.

МГНОВЕННОЕ СОХРАНЕНИЕ:
После дешифрования использованные ячейки немедленно сохраняются.


7. ТАЙМЕР БЕЗОПАСНОСТИ (Web Worker)

После загрузки книги запускается единый таймер на 2 минуты. Один таймер
на обе загруженные книги. Таймер работает в фоновом Web Worker и НЕ
приостанавливается при блокировке экрана или сворачивании браузера.
Время считается по реальным часам.

Как работает:
1. Загрузка первой книги — таймер на 2 минуты. Запрашивается 4-символьный
   пароль продления.
2. Загрузка второй книги — таймер сбрасывается на полные 2 минуты.
   Пароль не запрашивается повторно.
3. За 30 секунд до истечения — таймер становится оранжевым.
4. Истечение 2 минут — окно продления на 15 секунд. Нужно ввести пароль.
5. Верный пароль — таймер продлётся на 2 минуты.
6. Неверный пароль или бездействие — все книги шифруются, все поля
   очищаются.
7. Кнопка «Закрыть» — мгновенное шифрование и очистка.

ВАЖНО: Если вы заблокировали телефон на 20 минут, после разблокировки
таймер покажет 0 и немедленно зашифрует книги. Таймер не ждёт, пока
вы вернётесь — он работает по реальному времени.


8. СТАТИСТИКА И АУДИТ КНИГИ

1. Выберите книгу в блоке «Статистика книги».
2. Нажмите «Показать» — информация о заполнении.
3. «Просмотреть книгу» — содержимое в отдельном окне. [_] = удалено.
4. «Резервная копия» — сохранить в .json.


9. ДВУХКНИЖНАЯ СХЕМА ПЕРЕПИСКИ

— Вы шифруете своей книгой (Книга-1). Собеседник расшифровывает её копией.
— Собеседник шифрует своей книгой (Книга-2). Вы расшифровываете её копией.

ПОРЯДОК ДЕЙСТВИЙ:
1. Вы создаёте Книгу-1, шифруете Виженером, передаёте копию.
2. Собеседник создаёт Книгу-2, шифрует Виженером, передаёт копию вам.
3. Обмен координатами — через любые открытые каналы.
4. При истощении книги — создаётся новая.

ПОЧЕМУ ДВЕ КНИГИ:
— Компрометация одной книги раскрывает только одно направление.
— Каждый контролирует свою книгу.


10. НАСТРОЙКИ

— Язык: Русский / English (правый верхний угол).
— Тема: 🌙/☀️ — тёмная/светлая.
— Панель таймера: плавающая снизу.



11. КРИТИЧЕСКИЕ ПАРАМЕТРЫ БЕЗОПАСНОСТИ



11.1. ТРЕБОВАНИЯ К КНИГЕ

Книга ДОЛЖНА быть сгенерирована со следующими настройками:

— Включён «Крипто-генератор» (crypto.getRandomValues).
— Выбраны ВСЕ наборы символов (Русские, English, Символы, Пробелы).
— Алфавит книги должен быть максимально широким (рекомендуется
  не менее 200 уникальных символов).
— Размер книги подбирается под ожидаемую нагрузку.

Расчёт ёмкости (пример для книги на 10 000 ячеек):

При стандартной длине 40 символов — ~250 сообщений.
При 3–5 сообщениях в день — хватает на 50–80 дней.
Семь книг (по одной на день недели, всего 70 000 ячеек) —
примерно на год общения при среднем темпе.

Подбирайте размер под свой темп. Книга должна заканчиваться
не посреди сеанса. Если книга подходит к концу — используйте
раздел 15 для плановой замены.


11.2. ПРИНЦИП СВЕЖЕСТИ КНИГИ

Чем чаще заменяется книга — тем лучше. Это как вода в баке:

— Оставите на неделю — протухнет.
— Обновляете постоянно — свежая, бак чистый.

Долгоживущая книга накапливает дыры. Короткоживущая — не оставляет
следа.

Рекомендации:
— Малая нагрузка: менять раз в месяц.
— Средняя: раз в неделю (ротация по дням, раздел 14.1).
— Высокая или параноидальный режим: каждый день или каждый сеанс
  (раздел 14.2).


11.3. УТИЛИЗАЦИЯ ИСПОЛЬЗОВАННОЙ КНИГИ

Книга с дырами бесполезна. Она не содержит информации о переписке.
Она не восстановит ни одного сообщения. Её единственная ценность —
неиспользованные ячейки. Но держать её ради них бессмысленно.

Правило:
— Перешли на новую книгу — СРАЗУ удалите старую.
— Не накапливайте дырявые книги в IndexedDB.
— Противник, захвативший использованную книгу, не получает НИЧЕГО.


11.4. ТРЕБОВАНИЯ К КЛЮЧУ ВИЖЕНЕРА

— Длина ключа: не менее 40–60 символов.
— Ключ должен быть случайным.
— Хранить отдельно от книги.
— При личной встрече: бумага, уничтожить после запоминания.
— При замене книги — заменить ключ. Старый уничтожить.


11.5. ТРЕБОВАНИЯ К АЛФАВИТУ ВИЖЕНЕРА

— Максимальная длина (поле «Алфавит»).
— Нажать «Перемешать» для изменения порядка.
— Получатель использует ТОЧНО такой же.
— Передать вместе с ключом на первой встрече.



12. ЗАЩИТА ОТ АНАЛИЗА ТРАФИКА: ФИКСИРОВАННАЯ ДЛИНА


Для предотвращения анализа длины сообщений используйте следующий
протокол:

1. Заранее договоритесь с получателем о СТАНДАРТНОЙ ДЛИНЕ сообщений
   (например: 40, 60 или 100 символов). Эта длина едина для всего
   сеанса связи.

2. При шифровании:
   — Введите осмысленный текст.
   — Если он короче стандартной длины — добейте сообщение случайными
     символами до стандартной длины. Используйте виртуальную клавиатуру
     в случайном режиме для генерации мусора.
   — Если текст длиннее — разбейте на несколько сообщений, каждое
     стандартной длины.

3. При расшифровке:
   — Вы получите сообщение стандартной длины.
   — Прочитайте осмысленное начало. Хвост из случайных символов
     ИГНОРИРУЙТЕ.
   — Ориентируйтесь на смысл, а не на конец строки.

4. Счётчик символов над полем ввода и над полем результата помогает
   контролировать длину.

ЧТО ЭТО ДАЁТ:
Перехватчик видит только количество координат. Все сообщения имеют
одинаковое количество координат. Невозможно определить, где
короткая команда «OK», а где длинный приказ. Анализ трафика
бесполезен.

ПРИ ИСТОЩЕНИИ КНИГИ:
Количество использованных ячеек всегда кратно стандартной длине.
Противник, захвативший книгу с дырами, не узнает, сколько
осмысленных символов было в каждом блоке — только общее количество
блоков.



13. УСТОЙЧИВОСТЬ К АКТИВНОМУ ВМЕШАТЕЛЬСТВУ (MITM)


Активный противник может перехватывать и ИЗМЕНЯТЬ координаты
в канале связи. Система имеет встроенную защиту от этой угрозы
без необходимости в дополнительных кодах аутентификации.

КАК ЭТО РАБОТАЕТ:

— Если противник изменяет хотя бы одну координату в шифротексте,
  получатель расшифрует сообщение и получит КАШУ — бессмысленный
  набор символов.
— Это происходит потому, что сдвиг даже на одну ячейку в случайной
  книге немедленно ломает ВСЁ сообщение. Символы в книге случайны,
  поэтому подмена даёт не «почти правильный» текст, а визуально
  очевидный мусор.
— Получатель ВИДИТ, что сообщение повреждено, и понимает: было
  вмешательство.

ДЕЙСТВИЯ ПРИ ОБНАРУЖЕНИИ ВМЕШАТЕЛЬСТВА:

1. Получатель получает кашу вместо текста.
2. Немедленно прекратить использование скомпрометированной книги.
3. Связаться с отправителем по РЕЗЕРВНОМУ каналу и сообщить:
   «Книга скомпрометирована. Пересоздаём.»
4. Обе стороны генерируют НОВУЮ книгу, шифруют Виженером,
   обмениваются.
5. Связь продолжается с новой книгой.

ВАЖНО: Противник НЕ МОЖЕТ подменить сообщение так, чтобы получатель
принял ложный текст за настоящий. Система самодиагностируется.
Единственное, чего может добиться противник — временно нарушить
связь (DoS). Содержание переписки остаётся защищённым.



14. РАСШИРЕННЫЕ СХЕМЫ УПРАВЛЕНИЯ КНИГАМИ

Для максимальной защиты рекомендуется использовать не одну пару
книг, а систему ротации.

14.1. БАЗОВАЯ РОТАЦИЯ: ОДНА КНИГА В ДЕНЬ

— Создайте 7 комплектов книг (по одному на каждый день недели).
— Каждый комплект: Книга-отправителя и Книга-получателя.
— Понедельник — Комплект-1. Вторник — Комплект-2. И так далее.
— Каждый комплект шифруется СВОИМ ключом Виженера.

ЧТО ЭТО ДАЁТ:
Компрометация ключа от одного дня раскрывает переписку только
за этот день недели. Остальные дни не тронуты.

14.2. ПРОДВИНУТАЯ РОТАЦИЯ: КОМПЛЕКТ НА КАЖДЫЙ СЕАНС

— Заранее создайте N комплектов книг (например, 30 штук).
— Каждый комплект используется ОДИН РАЗ для одного сеанса связи.
— После завершения сеанса комплект УНИЧТОЖАЕТСЯ (удалить обе книги).
— Следующий сеанс — следующий комплект.

ЧТО ЭТО ДАЁТ:
Даже при полной компрометации устройства после сеанса противник
найдёт только использованные (дырявые) книги. История переписки
не восстановлена (Амнезия). Будущие сеансы не скомпрометированы
(ключи разные).



15. ПЕРЕДАЧА НОВЫХ КЛЮЧЕЙ ЧЕРЕЗ ИСТОЩЁННУЮ КНИГУ


Когда книга подходит к концу (осталось мало ячеек), можно

1. Отправитель пишет сообщение вида:

2. Сообщение шифруется остатками СТАРОЙ книги.
3. Получатель расшифровывает, получает новые параметры.
4. Обе стороны генерируют новые книги, шифруют новым ключом,

5. Старая книга уничтожается.

16. РУЧНОЙ РЕЖИМ: ШИФРОВАНИЕ НА БУМАГЕ


Система StrikeCipheeSVA спроектирована так, что может работать
полностью автономно, без компьютера и электричества. Всё, что нужно —
распечатанная книга, карандаш и линейка.


16.1. КОГДА ЭТО НУЖНО

— Отсутствие электричества или устройств.

2. Нажмите «Просмотреть книгу» в разделе «Статистика книги».

4. Создайте ДВА экземпляра: для себя и для получателя.

5. ПЕРЕДАЧА КНИГИ ПОЛУЧАТЕЛЮ

   Книга — это случайный набор символов. Без контекста она
   бесполезна для постороннего. Однако в момент передачи книга
   уязвима: если противник скопирует её ДО начала переписки,
   он сможет расшифровывать все будущие сообщения.

   ВАЖНО: первая передача — самая безопасная. Никто ещё не знает

   максимально надёжно.

   После первой передачи личные встречи больше не нужны. Далее
   система работает автономно: новые книги и ключи передаются
   внутри шифрованных сообщений (раздел 15).

   СПОСОБ 1 — ЛИЧНАЯ ВСТРЕЧА (наиболее надёжный):

   Отправитель и получатель встречаются лично. Книга передаётся

   СПОСОБ 2 — ЗАКЛАДКА (наиболее анонимный):

   Отправитель оставляет книгу в условленном месте. Сообщает
   получателю координаты тайника по оговорённому каналу.
   Получатель забирает. Прямого контакта нет. Лица не видят.
   Идеальная анонимность.

   ПРЕДУПРЕЖДЕНИЕ: если за вами УЖЕ следят на момент закладки,
   противник найдёт книгу раньше получателя. Но на этапе первой
   передачи это маловероятно — слежки ещё нет. В дальнейшем
   закладки не нужны: система работает автономно (раздел 15).

   СПОСОБ 3 — ДОВЕРЕННЫЙ КУРЬЕР (запасной):

   Если личная встреча и закладка невозможны — передача через
   доверенное лицо. Это должен быть человек, которому вы доверяете
   безоговорочно. Не нанятый курьер. Свой.

   Требования:
   — Книга в непрозрачном запечатанном конверте.
   — Доверенное лицо знает: конверт нельзя вскрывать,
     фотографировать, сканировать, показывать кому-либо.
   — Передача из рук в руки.
   — После вручения получатель подтверждает получение.
   — Если конверт повреждён — книга скомпрометирована.
     Уничтожить. Создать новую.

   ПОМНИТЕ: доверенное лицо — точка уязвимости. Если есть
   сомнения — используйте личную встречу или закладку.

6. После успешной передачи цифровую копию книги уничтожьте

16.3. ШИФРОВАНИЕ ВРУЧНУЮ (отправитель)

1. Положите распечатку книги перед собой.
2. На отдельном листе напишите сообщение.
3. Для КАЖДОГО символа сообщения:

   а) Найдите в книге ЛЮБУЮ ячейку с таким же символом.
   б) Убедитесь, что эта ячейка ещё не зачёркнута.
   в) Запишите координаты: страница:строка:позиция.
      Например: 3:14:7
   г) ЗАЧЕРКНИТЕ ячейку в своей книге. Жирно. Навсегда.

4. Добавьте мусор до стандартной длины (раздел 12).
5. Набор координат — это ваш шифротекст. Например:
   3:14:7, 12:5:33, 7:22:18, 1:41:9, ...

6. Передайте координаты получателю любым способом:
   — Радио, голосом (цифры легко диктовать).
   — Записка через курьера.
   — Азбука Морзе.
   — Телефонный звонок (продиктовать вслух, после чего оба
     синхронно зачёркивают ячейки).


16.4. ДЕШИФРОВАНИЕ ВРУЧНУЮ (получатель)

1. Положите свою копию книги перед собой.
2. Возьмите полученные координаты.
3. Для КАЖДОЙ координаты:

   а) Найдите в книге ячейку: страница, строка, позиция.
   б) Прочитайте символ. Запишите его.
   в) ЗАЧЕРКНИТЕ ячейку. Жирно. Навсегда.

4. Прочитайте сообщение. Игнорируйте хвост из мусора
   (раздел 12 — фиксированная длина).


16.5. СИНХРОНИЗАЦИЯ КНИГ ВРУЧНУЮ

При ручном режиме критически важно, чтобы отправитель и получатель
зачёркивали ОДНИ И ТЕ ЖЕ ячейки. Для этого:

ПРАВИЛО: отправитель ВСЕГДА ищет ПЕРВУЮ свободную ячейку
с нужным символом при просмотре книги ПО ПОРЯДКУ:

   Страница 1 → Страница 2 → ... → последняя страница.
   На каждой странице: Строка 1 → Строка 2 → ... → последняя.
   В каждой строке: Позиция 1 → Позиция 2 → ... → последняя.

Получатель, расшифровывая координаты, автоматически зачёркивает
те же ячейки.

Почему важен порядок:
— Отправитель не может дважды использовать одну ячейку.
— Получатель гарантированно зачёркивает то же, что и отправитель.
— Книги остаются синхронными.


16.6. ГЕНЕРАЦИЯ СЛУЧАЙНОЙ КНИГИ БЕЗ КОМПЬЮТЕРА

Если компьютер недоступен, случайную книгу можно создать вручную.
Трудоёмкость: книга на 10 000 ячеек — несколько часов работы.
Но результат — ключ, который невозможно восстановить.

СПОСОБ 1 — ИГРАЛЬНЫЕ КОСТИ:

1. Составьте алфавит (например, 64 символа).
2. Пронумеруйте каждый символ от 1 до 64.
3. Для каждой ячейки книги:
   — Бросьте две кости (даёт 36 вариантов).
   — Бросьте ещё раз для уточнения (36×36 = 1296).
   — Возьмите результат по модулю размера алфавита.
   — Запишите символ в ячейку.

СПОСОБ 2 — МЕШОК С ЖЕТОНАМИ:

1. Подготовьте жетоны с символами алфавита.
2. Количество жетонов каждого символа — равное.
3. Для каждой ячейки: вытащите жетон, запишите символ,
   ВЕРНИТЕ жетон обратно.
4. Перемешайте. Следующая ячейка.

СПОСОБ 3 — ТАБЛИЦА СЛУЧАЙНЫХ ЧИСЕЛ:

1. Возьмите книгу случайных чисел.
2. Каждое число преобразуйте в символ вашего алфавита.
3. Записывайте подряд.


16.7. ОСОБЕННОСТИ РУЧНОГО РЕЖИМА

Генерация книги в цифровом режиме занимает доли секунды,
в ручном — несколько часов. Но после создания книга работает
одинаково надёжно в обоих режимах.

Шифрование и дешифрование вручную занимают минуты на сообщение
(против мгновенного в цифровом режиме). Это плата за полное
отсутствие цифрового следа.

Виженер в ручном режиме не используется. Книга передаётся
в открытом виде — но она бессмысленна для постороннего.
Случайный набор символов без контекста невозможно ни прочитать,
ни идентифицировать как ключ.

Таймер безопасности в ручном режиме заменяется дисциплиной:
получил координаты — расшифровал — зачеркнул — убрал книгу
в надёжное место.

Цифровой след в ручном режиме отсутствует полностью. Нет логов,
нет излучений, нет метаданных. Только бумага, карандаш и голос
в эфире.

Криптостойкость ручного режима равна цифровому при условии,
что книга случайна и не скомпрометирована при передаче.


16.8. УНИЧТОЖЕНИЕ

После того как книга истощена (все или почти все ячейки зачёркнуты):

1. Сжечь распечатку. Полностью. До пепла.
2. Пепел развеять (не оставлять в одном месте).
3. Создать новую книгу (раздел 3 или 16.6).

Использованная бумажная книга с дырами так же бесполезна
для противника, как и цифровая (раздел 11.3). Но бумагу
можно потрогать. Поэтому — сжечь.

16.9. ЯЗЫКОВАЯ УНИВЕРСАЛЬНОСТЬ КНИГИ

Книга, сгенерированная с полным набором символов (русские, английские,
символы, цифры), покрывает практически все звуки, которые может
произнести человек. Русская «А» и английская «A» — один и тот же звук.
Русская «М» и английская «M» — один звук. Поэтому книга не привязана
к конкретному языку.

Для передачи сообщения на любом языке достаточно записать его
транслитом — через символы, передающие те же звуки. Пушту, арабский,
китайский (пиньинь), суахили, любой другой язык — всё может быть
записано символами из книги. Книга универсальна.

16.10. НЕВОЗМОЖНОСТЬ ДОКАЗАТЕЛЬСТВА РАСШИФРОВКИ

Даже если противник обладает неограниченной вычислительной мощностью
и переберёт все возможные варианты сообщений для перехваченных
координат, он получит тысячи осмысленных вариантов: «привет»,
«атакуем», «отмена», «ждать». Все они одинаково возможны, потому что
книга случайна. В ней нет закономерностей, которые могли бы указать
на правильный вариант.

Использованные ячейки уничтожены. Информация о том, какой из тысяч
вариантов был настоящим, больше не существует во Вселенной.
Доказать, какое именно сообщение было отправлено, невозможно.
Никакой мощностью. Никаким компьютером. Никогда.

USER MANUAL (ENGLISH)



1. GENERAL DESCRIPTION

StrikeCipherSVA is a text encryption tool based on the book cipher method
with marking of used cells and deletion of the symbol in the cell
(Amnesic Book Cipher — symbol amnesia).

The program is a single HTML file that runs in any modern browser.
No installation or internet connection required. All data is stored
locally in the browser's IndexedDB.

CORE PRINCIPLE:
A Book is a three-dimensional array (Pages × Rows × Characters).
During encryption, each character is replaced by coordinates of a random
free cell containing the same character. The used cell is immediately
DELETED — the symbol is destroyed, null remains. Without the book,
coordinates look like random numbers.

KEY DIFFERENCE from classical book cipher:
Used cells are marked, then the symbol is destroyed. The book does NOT
remember which symbols were used. After the session, it is impossible
to prove what was in any cell. This is "book amnesia" (Amnesic Book).
Even with full access to the book post factum, message content
cannot be recovered.

11. CRITICAL SECURITY PARAMETERS



11.1. BOOK REQUIREMENTS

The book MUST be generated with the following settings:

— "Crypto-generator" enabled (crypto.getRandomValues).
— ALL character sets selected (Russian, English, Symbols, Spaces).
— The book's alphabet must be as wide as possible (at least
  200 unique characters recommended).
— Book size is chosen based on expected usage.

Capacity estimate (example for a 10,000 cell book):

At a standard length of 40 characters — ~250 messages.
At 3–5 messages per day — enough for 50–80 days.
Seven books (one per day of the week, 70,000 cells total) —
enough for about a year of communication at an average pace.

Choose the size according to your pace. The book should not run out
mid-session. If the book is nearing depletion — use Section 15
for a planned replacement.


11.2. BOOK FRESHNESS PRINCIPLE

The more often a book is replaced, the better. It's like water in a tank:

— Leave it for a week — it goes stale.
— Refresh it constantly — it stays fresh, the tank stays clean.

A long-lived book accumulates holes. A short-lived book leaves no trace.

Recommendations:
— Light usage: replace once a month.
— Medium usage: once a week (daily rotation, Section 14.1).
— Heavy usage or paranoid mode: every day or every session
  (Section 14.2).


11.3. DISPOSAL OF USED BOOKS

A book with holes is useless. It contains no information about
the correspondence. It cannot recover a single message. Its only
value — unused cells. Holding onto it for those is pointless.

Rule:
— Switched to a new book — DELETE the old one IMMEDIATELY.
— Do not accumulate hole-ridden books in IndexedDB.
— An adversary who captures a used book gets NOTHING.


11.4. VIGENÈRE KEY REQUIREMENTS

— Key length: at least 40–60 characters.
— The key must be random.
— Store separately from the book.
— For in-person exchange: use paper, destroy after memorizing.
— When replacing a book — replace the key. Destroy the old one.


11.5. VIGENÈRE ALPHABET REQUIREMENTS

— Maximum length ("Alphabet" field).
— Press "Shuffle" to randomize the order.

— Exchange together with the key at the first meeting.



12. TRAFFIC ANALYSIS PROTECTION: FIXED MESSAGE LENGTH


To prevent message length analysis, use the following protocol:

1. Agree on a STANDARD MESSAGE LENGTH with your contact in advance
   (e.g., 40, 60, or 100 characters). This length is uniform
   for the entire communication session.

2. When encrypting:
   — Enter your meaningful text.
   — If it's shorter than the standard length — pad the message
     with random characters up to the standard length. Use the
     virtual keyboard in random mode to generate padding.
   — If it's longer — split into multiple messages, each of
     standard length.

3. When decrypting:
   — You will receive a message of standard length.
   — Read the meaningful beginning. IGNORE the tail of random
     characters.
   — Focus on meaning, not on where the string ends.

4. The character counter above the input field and above the result
   field helps you control the length.

WHAT THIS ACHIEVES:
An interceptor sees only the number of coordinates. All messages
have the same number of coordinates. It is impossible to determine
whether it was a short "OK" or a long directive. Traffic analysis
is useless.

WHEN THE BOOK IS DEPLETED:
The number of used cells is always a multiple of the standard length.
An adversary who captures a book with holes cannot determine how many
meaningful characters were in each block — only the total number
of blocks.



13. RESISTANCE TO ACTIVE INTERFERENCE (MITM)


An active adversary may intercept and MODIFY coordinates in the
communication channel. The system has built-in protection against
this threat without the need for additional authentication codes.

HOW IT WORKS:

— If the adversary changes even a single coordinate in the ciphertext,
  the recipient will decrypt the message and get GARBAGE — a meaningless
  string of characters.
— This happens because a shift of even one cell in a random book
  instantly breaks the ENTIRE message. The characters in the book
  are random, so a substitution produces not "almost correct" text
  but visually obvious garbage.
— The recipient SEES that the message is corrupted and understands:
  interference has occurred.

ACTIONS UPON DETECTING INTERFERENCE:

1. The recipient receives garbage instead of text.
2. Immediately stop using the compromised book.
3. Contact the sender via a BACKUP channel and report:
   "Book compromised. Recreating."
4. Both parties generate a NEW book, encrypt with Vigenère, exchange.
5. Communication continues with the new book.

IMPORTANT: The adversary CANNOT substitute a message so that the
recipient accepts fake text as genuine. The system is self-diagnosing.
The only thing the adversary can achieve is temporary disruption
(DoS). The content of the correspondence remains protected.



14. ADVANCED BOOK MANAGEMENT SCHEMES


For maximum protection, it is recommended to use not a single pair
of books but a rotation system.

14.1. BASIC ROTATION: ONE BOOK PER DAY

— Create 7 book sets (one for each day of the week).
— Each set: Sender's Book and Recipient's Book.
— Monday — Set-1. Tuesday — Set-2. And so on.
— Each set is encrypted with its OWN Vigenère key.

WHAT THIS ACHIEVES:
Compromise of one day's key reveals correspondence only for that
day of the week. The other days remain untouched.

14.2. ADVANCED ROTATION: ONE SET PER SESSION

— Create N book sets in advance (e.g., 30 sets).
— Each set is used ONCE for a single communication session.
— After the session ends, the set is DESTROYED (delete both books).
— Next session — next set.

WHAT THIS ACHIEVES:
Even with full device compromise after a session, the adversary finds
only used (hole-ridden) books. Communication history is not recovered
(Amnesia). Future sessions are not compromised (different keys).



15. TRANSMITTING NEW KEYS VIA A DEPLETED BOOK


When a book is nearing depletion (few cells remain), you can transmit
the parameters of a NEW book directly in an encrypted message:

1. The sender writes a message like:
   "New book: alphabet=..., key=..., rounds=17. Start tomorrow."
2. The message is encrypted with the remainder of the OLD book.
3. The recipient decrypts it and receives the new parameters.
4. Both parties generate new books, encrypt with the new key, exchange.
5. The old book is destroyed.

WHAT THIS ACHIEVES:
The first in-person meeting is needed only ONCE. After that, the system
is self-sustaining through the secure channel. Keys are transmitted
inside encrypted messages. The circle is closed.



16. MANUAL MODE: PAPER-ONLY ENCRYPTION


The StrikeCipheeSVA system is designed to operate fully offline,
without a computer or electricity. All you need is a printed book,
a pencil, and a ruler.


16.1. WHEN THIS IS NEEDED

— No electricity or devices available.
— Complete isolation from digital traces (no emissions, logs,
  metadata).
— Transmission via courier, pigeon post, or voice over radio.
— The last backup channel when everything else is compromised.


16.2. PREPARING A BOOK FOR PRINTING

1. Generate a book in the program (Section 3).
2. Click "View Book" in the "Book Statistics" section.
3. Print the contents. Print structure:

   Page 1
   Row  1: ж Щ ъ Ф ы В а П р 2 ] k L о Q . Д ~ я 7 ...
   Row  2: U 3 й ш Ё © Ю м ь T + Ж { ч ъ Х 9 ; „ ...
   ...

4. Create TWO copies: one for yourself, one for the recipient.

5. TRANSFERRING THE BOOK TO THE RECIPIENT

   The book is a random collection of symbols. Without context,
   it is useless to an outsider. However, during transfer, the book
   is vulnerable: if an adversary copies it BEFORE communication
   begins, they will be able to decrypt all future messages.

   IMPORTANT: The first transfer is the safest. No one knows about
   your connection yet. You are not under surveillance because there
   is no reason to be. The target of observation does not exist.
   Use this moment as reliably as possible.

   After the first transfer, in-person meetings are no longer needed.
   The system then operates autonomously: new books and keys are
   transmitted inside encrypted messages (Section 15).

   METHOD 1 — IN-PERSON MEETING (most reliable):

   The sender and recipient meet in person. The book is handed over
   directly. You see the recipient's face. You see that the book
   reached exactly the right person. No intermediaries, no copies.

   METHOD 2 — DEAD DROP (most anonymous):

   The sender leaves the book at a prearranged location. They send
   the recipient the coordinates of the hiding spot via an agreed
   channel. The recipient picks it up. No direct contact. Faces
   are not seen. Ideal anonymity.

   WARNING: If you are ALREADY under surveillance at the time of
   the dead drop, the adversary will find the book before the
   recipient. However, at the first transfer stage, this is unlikely —
   there is no surveillance yet. After the first transfer, dead drops
   are no longer needed: the system works autonomously (Section 15).

   METHOD 3 — TRUSTED COURIER (backup):

   If an in-person meeting and a dead drop are both impossible —
   transfer via a trusted person. This must be someone you trust
   unconditionally. Not a hired courier. One of your own.

   Requirements:
   — The book must be in a sealed, opaque envelope.
   — The trusted person knows: the envelope must not be opened,
     photographed, scanned, or shown to anyone.
   — Hand-to-hand transfer only.
   — After delivery, the recipient confirms receipt.
   — If the envelope is damaged — the book is compromised.
     Destroy it. Create a new one.

   REMEMBER: A trusted person is a vulnerability. If there is any
   doubt — use an in-person meeting or a dead drop.

6. After successful transfer, destroy the digital copy of the book
   (Section 11.3).


16.3. ENCRYPTING BY HAND (sender)

1. Place the printed book in front of you.
2. On a separate sheet, write your message.
3. For EACH character of the message:

   a) Find ANY cell in the book with the same character.
   b) Make sure this cell has not been crossed out yet.
   c) Write down the coordinates: page:row:position.
      Example: 3:14:7
   d) CROSS OUT the cell in your book. Firmly. Forever.

4. Add padding to the standard length (Section 12).
5. The set of coordinates is your ciphertext. Example:
   3:14:7, 12:5:33, 7:22:18, 1:41:9, ...

6. Transmit the coordinates to the recipient by any means:
   — Radio, spoken aloud (numbers are easy to dictate).
   — A note via courier.
   — Morse code.
   — Phone call (dictate aloud, then both cross out cells
     simultaneously).


16.4. DECRYPTING BY HAND (recipient)

1. Place your copy of the book in front of you.
2. Take the received coordinates.
3. For EACH coordinate:

   a) Find the cell in the book: page, row, position.
   b) Read the character. Write it down.
   c) CROSS OUT the cell. Firmly. Forever.

4. Read the message. Ignore the tail of padding
   (Section 12 — fixed length).


16.5. SYNCHRONIZING BOOKS MANUALLY

In manual mode, it is critically important that the sender and
recipient cross out the SAME cells. To achieve this:

RULE: The sender ALWAYS searches for the FIRST free cell with
the needed character by scanning the book IN ORDER:

   Page 1 → Page 2 → ... → last page.
   On each page: Row 1 → Row 2 → ... → last row.
   In each row: Position 1 → Position 2 → ... → last position.

By decrypting the coordinates, the recipient automatically crosses
out the same cells.

Why order matters:
— The sender cannot use the same cell twice.
— The recipient is guaranteed to cross out what the sender did.
— The books remain synchronized.


16.6. GENERATING A RANDOM BOOK WITHOUT A COMPUTER

If a computer is unavailable, a random book can be created by hand.
Effort: a book of 10,000 cells takes several hours of work.
But the result is a key that is impossible to recover.

METHOD 1 — DICE:

1. Compile an alphabet (e.g., 64 characters).
2. Number each character from 1 to 64.
3. For each cell of the book:
   — Roll two dice (gives 36 possibilities).
   — Roll again for refinement (36×36 = 1296).
   — Take the result modulo the alphabet size.
   — Write the character in the cell.

METHOD 2 — BAG OF TOKENS:

1. Prepare tokens with the characters of the alphabet.
2. Equal number of tokens for each character.
3. For each cell: draw a token, write the character,
   RETURN the token to the bag.
4. Shake. Next cell.

METHOD 3 — RANDOM NUMBER TABLE:

1. Take a book of random numbers.
2. Convert each number to a character from your alphabet.
3. Write them down in sequence.


16.7. CHARACTERISTICS OF MANUAL MODE

Book generation in digital mode takes a fraction of a second;
in manual mode — several hours. But once created, the book works
equally reliably in both modes.

Encryption and decryption by hand take minutes per message
(versus instantaneous in digital mode). This is the price for
a complete absence of digital traces.

Vigenère is not used in manual mode. The book is transferred
in plain form — but it is meaningless to an outsider. A random
set of characters without context cannot be read or even
identified as a key.

The security timer in manual mode is replaced by discipline:
receive coordinates — decrypt — cross out — put the book away
in a safe place.

Digital footprint in manual mode is completely absent. No logs,
no emissions, no metadata. Only paper, pencil, and a voice on
the air.

The cryptographic strength of manual mode equals digital mode,
provided the book is random and uncompromised during transfer.


16.8. DESTRUCTION

When the book is depleted (all or nearly all cells crossed out):

1. Burn the printout. Completely. To ashes.
2. Scatter the ashes (do not leave in one place).
3. Create a new book (Section 3 or 16.6).

A used paper book with holes is just as useless to an adversary
as a digital one (Section 11.3). But paper can be touched.
Therefore — burn it.

16.9. LANGUAGE UNIVERSALITY OF THE BOOK

A book generated with the full character set (Russian, English, symbols,
digits) covers virtually all sounds a human can produce. Russian «А»
and English «A» are the same sound. Russian «М» and English «M» are the
same sound. Therefore, the book is not tied to any specific language.

To transmit a message in any language, simply write it in transliteration —
using characters that convey the same sounds. Pashto, Arabic, Chinese
(pinyin), Swahili, any other language — all can be written using the
characters from the book. The book is universal.

16.10. IMPOSSIBILITY OF PROOF AFTER DECRYPTION

Even if an adversary possesses unlimited computing power and brute-forces
all possible message variants for intercepted coordinates, they will
obtain thousands of meaningful options: "hello", "attack", "cancel",
"wait". All are equally possible because the book is random. It contains
no patterns that could point to the correct variant.

The used cells are destroyed. The information about which of the
thousands of variants was the real one no longer exists in the Universe.
It is impossible to prove which message was sent. By any power.
By any computer. Ever.
